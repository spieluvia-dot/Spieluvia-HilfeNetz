# Quelle 02: DAJEB Beratungsführer – Rechte- und Datenprüfung

Prüfdatum: 2026-11-06. Status: **Recherche dokumentiert, keine Datenübernahme autorisiert**.

## Gesicherte Erkenntnisse
- Offizielle Suche: https://www.dajeb.de/beratungsfuehrer-online/beratung-in-ihrer-naehe
- 14.093 Beratungsstellen (Stand 13.10.2026 laut Suchseite); ca. 14-tägige Aktualisierung.

- Einträge werden von Beratungsstellen gepflegt bzw. Änderungen und Löschungen gemeldet; keine Garantie, dass jedes einzelne Detail aktuell ist.
- **Wichtig: offizieller Adressenservice gegen Kostenerstattung**, beschränkt auf bestimmte Institutionstypen (u.a. Behörden, gemeinnützige Organisationen, Hochschulen). Spieluvias rechtlicher Status muss geprüft werden.
- Eine freie Lizenz, kostenlose Gesamtexportmöglichkeit oder öffentlich nutzbare API konnte nicht bestätigt werden.

## Freigabeanfrage
1. Ist für ein kostenloses, öffentliches und datensparsames Hilfsverzeichnis eine **kostenfreie** Datenübernahme möglich, auch wenn der Projektbetreiber keine anerkannte Gemeinnützigkeit nachweisen kann?
2. Welche konkreten Felder und Kategorien dürfen gespeichert, in einer Umkreissuche angezeigt und als vCard heruntergeladen werden?
3. Bestehen Auflagen zu Namensnennung, Lizenz, Nachveröffentlichung, Löschung und Updates?
4. Gibt es eine offizielle Exportdatei, API oder einen vereinbarten regelmäßigen Änderungsabgleich?
5. Dürfen nur einzelne, unabhängig anhand der Träger-Websites verifizierte Einrichtungen aufgenommen werden, ohne die DAJEB-Datenbank als Quelle zu kopieren?

## Entscheidung
**Kein Datenimport und kein Scraping des gesamten DAJEB-Bestands ohne geklärte Nutzungsrechte.** Unabhängige Einzelfallrecherche auf offiziellen Websites bleibt möglich. Keine kostenpflichtigen Angebote beauftragen.
